Why this exists

This site is a test bed for a GitHub-connected deployment workflow. It covers the full loop: write code locally, open a pull request, get it reviewed, and deploy — all driven from the command line with Claude.

Every section of this page maps to a phase in the project. Issues were created automatically, branches were cut, and PRs were generated without leaving the editor.

    Deploy on request

    Say the word and Claude commits, pushes, and opens the PR.
